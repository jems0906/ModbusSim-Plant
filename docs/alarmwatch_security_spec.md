# AlarmaWatch Security Observation Scope

Version 1.0.0. This is the explicit security-observation scope for the local training simulation; it is not a production ICS security specification.

## Data source and boundary

AlarmaWatch reads the ModbusSim Plant audit API over loopback. The server audit is generated by pymodbus request, response, and connection hooks. AlarmaWatch performs no Modbus writes and does not inspect packet payloads, client IP addresses, authenticated identities, or traffic outside this simulator.

## Observations

| ID | Input | Observation | Severity |
| --- | --- | --- | --- |
| SEC-001 | A Modbus write request whose address range is rejected by the simulator register map | Rejected write request, function code, mapped address, unit ID, transaction ID, and timestamp | Medium |
| SEC-002 | A request whose function code is not one of FC01, FC03, FC04, FC05, FC06, or FC16 | Unsupported function request and function code | High |
| MET-001 | A Modbus exception response | Increment the protocol-exception counter; do not treat an exception alone as malicious | Informational metric |

Writes allowed by the register map are recorded by the simulator audit but are not automatically labeled suspicious: operator setpoint writes are expected in this training project. Connection open/close events are visible in the audit UI, but are not attributed to an IP or identity.

## Acceptance checks

- A rejected FC06/FC16/FC05 request creates one SEC-001 observation.
- An unknown function code creates one SEC-002 observation.
- A valid mapped write creates no security observation.
- Exception responses increment a counter without generating a security finding by themselves.
- Re-reading overlapping audit windows does not duplicate findings.
- Audit-source failure appears as unavailable telemetry, not as “no suspicious activity.”
- The API exposes findings read-only; it cannot change the simulator or block requests.

AlarmaWatch is not a packet monitor, intrusion-prevention system, incident-response tool, authenticated audit service, safety system, or production-ready security appliance. Findings are simulator observations, not proof of malicious activity.
